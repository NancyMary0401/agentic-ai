Agentic Loan Processing Architecture

Sep-23 personal-loan proof of concept: one main orchestrator coordinates specialised agents, services, state, and human escalation.

Key idea: there is one main controller, LoanAgentOrchestrator. It uses LangGraph to remember workflow state and an LLM through LangChain to select approved specialised tools.

Control flow

Every specialised agent/tool returns a result to the shared LangGraph state. The orchestrator reads that updated state and continues to the next required step. This prevents duplicate questions and allows the session to resume later.
